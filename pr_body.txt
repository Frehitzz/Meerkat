## Summary
Implements Phase 6 of the Dashboard UI featuring a minimalist Black & White theme built with Tailwind CSS v4, direct Facebook login redirection to the dashboard, and a customer messages endpoint.

## Changes
- Updated `docs/wireframes/dashboard_login_wireframe.html` with a black and white color scheme and standard supporting accent colors.
- Created `meerkat-frontend/src/DashboardView.jsx` containing the full 3-pane dashboard (sidebar navigation, live channels, message list with platform tags, detail view, read-only MVP banner, and sales/AI overview cards) styled using Tailwind CSS v4.
- Updated `meerkat-frontend/src/App.jsx` to parse Facebook OAuth callback query parameters, persist seller session in `sessionStorage`, and seamlessly transition to the dashboard.
- Updated `meerkat-backend/routes/auth.py` to redirect directly back to the frontend with seller query params upon successful Facebook Login.
- Created `meerkat-backend/routes/messages.py` to retrieve and filter customer messages by platform.
- Registered messages route in `meerkat-backend/main.py` and added automated test coverage in `meerkat-backend/test_main.py`.
