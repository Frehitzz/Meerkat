## Summary
Integrates automated testing (`Vitest` + `React Testing Library` + `jsdom`) and code formatting (`Prettier`) on the React frontend. Also resolves conflicting ESLint rules.

## Changes
- Installed `vitest`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom`, and `prettier` as devDependencies.
- Configured Vitest inside `vite.config.js` to run in a `jsdom` browser-like environment.
- Configured ESLint inside `eslint.config.js` to extend `eslint-config-prettier`, preventing styling rules conflicts.
- Created `jsconfig.json` to configure the modern automatic JSX transform for editors and compile tools.
- Created a global setup file `src/test/setup.js` to initialize DOM testing extensions and define React globally for tests.
- Created `src/App.test.jsx` to test the App component's loading, success, and fail API states.
- Cleaned and formatted the frontend codebase with `npm run format`.
